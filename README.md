# Tread

Platformer de instalación urbana para celular, en landscape.

Junta 8 rollos de coaxial y llega a la última casa a instalar el servicio.

## Local

```bash
npm install
npm run dev
```

Celular: horizontal + pad táctil. Desktop: flechas / WASD + espacio.

## Vercel

Build: `npm run build`  
Output: `dist`
